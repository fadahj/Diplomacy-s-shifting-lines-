# Diplomacy's shifting lines — chart of the week

Self-contained interactive chart (data, logo and code are inside index.html; only the Inter font loads from Google Fonts).

## Publish on GitHub Pages
1. Create a public repo, e.g. `diplomacy-chart`.
2. Upload `index.html` and `.nojekyll` to the repo root.
3. Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
4. After about a minute the chart is live at `https://YOUR-USERNAME.github.io/diplomacy-chart/`.

## Embed in Arc (HTML block)
```html
<div style="width:100%;max-width:1080px;margin:0 auto"><iframe src="https://YOUR-USERNAME.github.io/diplomacy-chart/" title="Diplomacy’s shifting lines" scrolling="no" loading="lazy" style="display:block;width:100%;aspect-ratio:1080/1350;border:0;overflow:hidden"></iframe></div>
```

## Updating
Replace `index.html` in the repo; the live article updates within a minute or two (no Arc edit needed).
